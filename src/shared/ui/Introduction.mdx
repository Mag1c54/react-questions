# UI-кит Yeahub

Набор базовых компонентов, из которых собирается весь интерфейс. Лежит в `src/shared/ui`.

## Как пользоваться

```tsx
import { Button, Input, Card } from "@/shared/ui";
```

Подключай компоненты только через `@/shared/ui`, а не по глубоким путям.

## Правила

- **Кит ничего не знает о проекте.** Компоненты не импортируют ничего из `entities`, `features`, `widgets`, `pages` и стора. Данные и поведение приходят через пропсы.
- **Нет логики запросов.** Только внешний вид, состояния и доступность.
- **Стили через переменные** из `styles/variables.scss`, без цветов и размеров «от руки».
- **Классы по BEM с префиксом `ui-`** (`ui-btn`, `ui-input__control`).
- **Доступность обязательна:** подписи, фокус с клавиатуры, `aria-*` для состояний.

## Как добавить компонент

1. Создай папку `src/shared/ui/<name>/` с `Component.tsx` и `component.scss`.
2. Напиши историю `Component.stories.tsx` с тегом `autodocs` и разбери все состояния.
3. Открой вкладку Accessibility и убедись, что нарушений нет.
4. Добавь экспорт в `src/shared/ui/index.ts`.
